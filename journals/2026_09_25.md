- [[Linking Notebooks in a Leather Folio]]
	- Consider notebooks n1, n2, n3 in that order which needs to be hooked onto 1 elastic band that is atached and woven into a leather folio.
	- Call this elastic band as EF1 (elastic folio 1)
	- Tie up a loose elastic band, EL1.
	- Link n1 and n3 using EL1. All this outside the leather folio.
	  logseq.order-list-type:: number
	- Pass these notebooks n1 and n3 thru EF1, such that each notebook is on either side of EF1. They should be somewhat secure inside the folio.
	  logseq.order-list-type:: number
	- Pass and attach n2 thru EF1 and n2 now acts as an achor for n1 and n3
