- #household #math #basics Calculator Memory Functions
	- M+, M-, MRC/MR
	- Consider this calculation...
	  ```
	  (15x3) + (4x4) - (15x4) - (2x3)
	    15   +   16  -   20   -   6
	    			  5
	  ```
	- The output of each of the brackets can be saved to **MEMORY** as either a + or - value. The outcome of the parallel memory operation can be **RECALLED**.
	  ```
	  15x3	= 15 M+
	  4x4		= 16 M+
	  15x4	= 20 M-
	  2x3		= 6  M-
	  MRC		  5
	  ```
